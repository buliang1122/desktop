# 阿B听书 Windows 桌面版 v1.0.2

在电脑上搜索和收听有声小说，支持书架续播、倍速播放、定时停止、离线缓存，以及全局隐藏和播放 / 暂停快捷键。

本项目是基于 [fengqiao57/abts](https://github.com/fengqiao57/abts) 的非官方 Windows 桌面移植，支持 Windows 10 / 11 x64，无需 Android 模拟器。

## 本次更新

### 窗口恢复状态修正

修复“音频继续播放、全局快捷键有效，但页面无法点击”的问题：手动恢复窗口后，同步 Electron / Chromium 的显示与页面焦点状态。

使用者已确认故障由此前的窗口状态同步问题导致，并在实际使用中验证修复有效。

### 本地诊断日志

新增窗口事件、页面异常、渲染进程退出、无响应、慢请求和运行心跳等日志，方便按故障时间排查。

- 打开方式：**设置 → 本地数据 → 诊断日志**。
- Alt 菜单的“诊断”支持记录当前状态和打开日志目录。
- 日志位置：`%APPDATA%\ABTS Desktop\logs`。
- 日志仅保存在本机，不自动上传；登录相关字段和 URL 查询参数会脱敏。
- 当前日志约 1 MB 后轮换，保留当前与上一份文件。

## 保留的桌面快捷功能

这些功能已在 1.0.1 提供，本版继续支持：

- **Ctrl + Alt + H：隐藏 / 取消隐藏**。隐藏后不显示任务栏或托盘图标，音频继续播放；取消隐藏仅恢复任务栏入口，保持最小化，不弹窗、不抢焦点。
- **Ctrl + Alt + P：全局播放 / 暂停**。窗口隐藏或其他软件在前台时同样可用。
- 两组快捷键均可自定义并保存。隐藏依据独立状态判断，不依赖窗口是否处于前台。
